# KCCAutomate priorities

One improvement per build, so each can be reviewed before the next release.
Installer and portable packaging accompany the first improvement.

1. **0.3.0 — Guided first-run setup: implemented.** Reader, folder access checks,
   installed-tool discovery and manual selection, isolated optional test book,
   opt-in scheduling, review. Installer and portable ZIP are built and fixture
   tested. Real converter, network-credential and Windows integration checks
   remain part of manual acceptance before publication.
2. **Next — Simple and Advanced views.** Make the common path easier to follow
   while keeping detailed conversion controls available.
3. **Sample-page visual preview.** Compare page fitting and spread handling
   before processing a full book.
4. **Network retry controls.** Recover from temporary share disconnections with
   visible status and bounded retries.
5. **Duplicate handling choices.** Explain existing-output conflicts and offer
   clear, deliberate choices.
6. **Archive versioning.** Optional version history before replacing an archived
   original.
7. **Tray controls.** Quick access to progress, pause/stop-after-file and opening
   the app.

Items 2–7 are planned, not included in 0.3.0.
